# Contributing to Smart CSV Profiler

Contributions should improve reproducibility, robustness, documentation, or transparent measurement.

1. Open an issue describing the problem, expected behavior, and a minimal safe example.
2. Use a branch; avoid committing passwords, API keys, private files, or identifying data.
3. Add or update tests for any code change. Record Python and package versions.
4. State which claims are empirically measured and which are conceptual or proposed.
5. For sensitive use cases, keep all sample data synthetic or appropriately de-identified.

Please follow the existing `LICENSE` terms. This repository does not promise maintenance or support response times.
