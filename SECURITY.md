# Responsible security disclosure

This is a research prototype and has not completed a production-security audit.

Do not publish exploits, credentials, real user records, or unconsented system data in issues. For a suspected security issue, use GitHub's private vulnerability reporting feature **if enabled** or contact the repository owner privately using an owner-published contact method.

No automated operations should be performed against third-party assets without permission. Defensive simulations should use non-production fixtures.
